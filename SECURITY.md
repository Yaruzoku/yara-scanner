# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Yara Scanner, please do not
open a public GitHub issue.

Instead, report it privately through GitHub's security advisories or
contact the project maintainer directly.

Please include:
- A description of the vulnerability
- Steps to reproduce it
- The affected version
- Any relevant logs or screenshots

## Scope

This policy applies to the Yara Scanner source code and official
release builds.

Third-party YARA rules, dependencies, and external tools are outside
the project's direct control, but relevant issues may still be
reported.

## Supported Versions

Only the latest released version is actively maintained for security
issues.
